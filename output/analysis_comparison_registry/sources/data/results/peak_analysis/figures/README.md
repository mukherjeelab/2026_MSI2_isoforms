# MSI2 fixed-peak visualization index

Figures are generated by `analysis/visualize_peak_deseq.R` and
`analysis/visualize_all_nonzero_peaks.R` from the existing raw count matrix,
full-library size factors, normalized counts, peak metadata, and separate paired
DESeq2 result tables. Every figure is saved as PDF and 300-dpi PNG. TSV files
beside the figures contain the plotted or selected data.

## Transformations and thresholds

- DESeq2 results are not refit or changed.
- Sample-level PCA and correlation use a blind DESeq2 variance-stabilizing
  transformation of peaks with total count >= 10 across all eight samples.
  Full mapped-library size factors are used.
- Pair ratios use `log2((IP + 0.5) / (input + 0.5))`; reported pair
  correlations use peaks that passed the existing per-construct count filter,
  while the plots and tables retain all 43,794 peaks.
- Significance means adjusted p-value < 0.05. The |log2FC| = 1 lines in volcano
  plots are visual references, not biological cutoffs.
- Heatmaps select up to 75 significantly enriched peaks with positive
  enrichment in both pairs and mean normalized input >= 1. They rank candidates
  by the sum of adjusted-p-value rank and effect-size rank. Values are
  `log2(normalized count + 0.5)` and then z-scored within each peak.
- `peak_score_max` is used for original omniCLIP validation because it preserves
  the strongest source peak represented by each merged region. Its x-axis is
  log10 scaled.
- Construct enrichment categories are descriptive. Significance in one
  construct but not the other is not a test of a construct difference.

## All peaks with any count

The `all_nonzero_peaks/` directory is a separate view of the 16,046 merged
peaks with a raw count greater than zero in at least one of the eight libraries.
It does not apply the existing per-construct DESeq2 count filters and does not
refit the differential-enrichment models.

- `PCA_16046_nonzero_peaks` uses a blind DESeq2 variance-stabilizing
  transformation with size factors derived from full mapped-library totals.
- `heatmap_16046_nonzero_peaks` displays all 16,046 peaks as per-peak z-scores
  of VST counts. Rows are grouped into eight deterministic k-means pattern
  clusters because labeling or hierarchically clustering all rows would not be
  interpretable.
- `CLIP_SMI_pseudocount_LFC_scatter` compares 328WT with 324WT using
  `log2((mean CLIP CPM + 0.5) / (mean SMI CPM + 0.5))`. The two CLIP replicates
  and two SMI replicates are averaged separately for each construct. Pair A,
  pair B, and mean-pair log-ratios are also retained in the accompanying TSV.
- Scatter colors provide context from the existing within-construct DESeq2
  enriched calls. They are descriptive and are not a construct-by-assay
  interaction test.
- `transcript_region_bias/continuous_construct_preference/` is the primary
  continuous transcript-region analysis. It retains all 16,046 peaks with any
  raw count, applies no delta-sign or preferred-construct filter, and compares
  delta-delta between transcript regions using an overall Kruskal-Wallis test,
  pairwise Wilcoxon rank-sum tests, and pairwise two-sample KS tests. The folder
  contains five-region distributions, density-binned 324WT-versus-328WT
  scatter facets, focused 3' UTR/intron density and ECDF plots, and all
  peak-level and statistical TSVs.
- `transcript_region_bias/continuous_construct_preference/quantile_normalized_log2cpm/`
  is a sensitivity analysis of the same 16,046 peaks. Raw counts are converted
  using full mapped-library CPM, transformed as `log2(CPM + 0.5)`, and
  quantile-normalized across all eight samples before construct enrichment and
  delta-delta are recalculated. It includes the normalized 16,046 by 8 matrix,
  remade continuous, density, and ECDF figures, and updated region tests.
- `transcript_region_bias/delta_LFC_by_transcript_region` is an older
  continuous view tied to the discrete workflow. It uses the relaxed
  positive-preferred filter and tests each region against zero; it is retained
  for provenance but is not the primary between-region analysis.
- Exact parameters and compact results are in `analysis_parameters.tsv` and
  `summary.tsv` within the directory.
- The parent `all_nonzero_peaks/transcript_region_bias/` directory contains
  the older summit-based, threshold-defined 324-biased, 328-biased, and
  Similar-positive group analysis. It is preserved as a descriptive analysis,
  including the 43,794 merged-peak and 46,108 source-peak backgrounds. Cached
  peak-to-region annotations are shared with the new continuous analysis.

## QC

- `QC/PCA_all_samples`: global sample behavior by assay and construct.
- `QC/sample_correlation_heatmap`: Pearson similarity of VST peak profiles.
- `QC/library_count_summary`: mapped depth, fixed-peak counts and percentage,
  nonzero peaks, and DESeq2 size factor.

## Within-construct results

Each `MSI2_328WT/` and `MSI2_324WT/` directory contains:

- `MA_IP_vs_input`: abundance versus IP/input effect size.
- `volcano_IP_vs_input`: effect size versus adjusted p-value.
- `enriched_peak_heatmap`: individual samples across reproducibly enriched
  peaks; columns are ordered Input A, IP A, Input B, IP B.
- `pair_reproducibility`: pair A versus pair B descriptive enrichment.

## Representative peaks

- `peak_examples/paired_peak_counts`: connected input-to-IP normalized counts
  for strong, intermediate, and pair-discordant examples.
- `selected_peak_examples.tsv` records the deterministic selection reason.

## Construct comparison and original-score validation

- `construct_comparison/328_vs_324_log2FC_scatter`: direct comparison of effect
  sizes for peaks tested in both separate analyses.
- `construct_comparison/enrichment_category_summary`: descriptive shared and
  construct-only enrichment categories.
- `construct_comparison/omniCLIP_score_vs_328_enrichment` and
  `omniCLIP_score_vs_324_enrichment`: original merged-region maximum score
  versus current enrichment, with score-quantile boxplots.
- `construct_comparison/combined_effect_size_heatmap`: curated common,
  328WT-biased, and 324WT-biased peak effects.

The compact numerical results are in `visualization_summary.tsv`; package
versions are recorded in `sessionInfo.txt`.
