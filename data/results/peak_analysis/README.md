# Fixed-peak CLIP results

These files were generated on Bodhi from eight legacy-processed, deduplicated
CLIP/input BAMs and downloaded into this repository on 2026-09-04. The BAMs are
not stored here, so the existing tables and figures can be inspected locally,
but featureCounts cannot be rerun locally without obtaining the BAMs.

The matching workflow, parameters, environments, and sample metadata are under
`code/clip_peak_analysis/`. The original fixed peak set is
`data/MSI2_peaks_omniCLIP.bed`.

## Contents

- `peak_count_matrix.tsv`: raw integer counts for 43,794 merged regions and all
  eight samples.
- `featurecounts.tsv` and `.summary`: original featureCounts output and
  assignment summary. BAM-column paths retain the original Bodhi locations.
- `peaks.filtered_merged.{bed,saf,tsv}`: filtered and same-strand-merged peak
  definitions.
- `peak_members.tsv`: source-peak provenance, including original scores and
  gene IDs.
- `bam_library_sizes.tsv`: primary mapped alignments used for full-library
  DESeq2 normalization.
- `deseq2/<construct>/`: paired IP-versus-input results, normalized counts,
  size factors, three-page QC PDF, and R session information.
- `audit/`: integrity, sample-QC, comparison, and shared-peak summaries created
  by `audit_results.R`.
- `figures/`: enrichment and quality-control figures, plotting tables, and a
  figure index generated by `analysis/visualize_peak_deseq.R`.

The primary construct-preference transcript-region analysis is continuous. It
uses all 16,046 merged peaks with a raw count above zero in at least one of the
eight libraries, calculates `324WT log2(CLIP/SMI) - 328WT log2(CLIP/SMI)`, and
tests whether that score differs among five transcript-region annotations. Its
figures, peak-level values, summaries, and Kruskal-Wallis, Wilcoxon, and
Kolmogorov-Smirnov results are under
`figures/all_nonzero_peaks/transcript_region_bias/continuous_construct_preference/`.
The older cutoff-based delta groups remain in the parent
`transcript_region_bias/` directory as a separate exploratory analysis.

## Integrity checks

The imported peak source reproduces the four prepared peak files exactly under
Python 3.12. Count-matrix values are non-negative integers; peak and sample IDs
match across files; and each sample's matrix column sum exactly equals its
featureCounts `Assigned` total. All expected output tables are present.

## Results

- Of 43,794 merged regions, 16,046 have at least one count across all samples;
  27,748 are zero throughout.
- Fixed-peak assignment is higher in IP than input for every matched pair. It is
  22.78% and 22.80% for the two 328WT IPs versus 5.22% and 4.71% for inputs;
  8.85% and 10.34% for the two 324WT IPs versus 3.67% and 4.12% for inputs.
- The total-count >= 10 filter leaves 2,769 tested peaks for 328WT and 1,546 for
  324WT.
- At adjusted p-value < 0.05, 328WT has 494 significant peaks (493 enriched and
  one depleted), while 324WT has 144, all enriched.
- Among 1,095 peaks tested in both constructs, fold changes are moderately
  concordant (Pearson r = 0.413; Spearman rho = 0.421). Eighty-six peaks are
  significantly enriched in both analyses.
- Original omniCLIP peak score has only a weak positive association with the new
  enrichment estimates (Spearman rho = 0.189 for 328WT and 0.169 for 324WT).

## Interpretation limits

The QC PCA plots show strong separation between IP replicates, especially for
324WT. Pair-specific log2 IP/input ratios also correlate weakly across tested
peaks (Spearman rho = 0.164 for 328WT and 0.192 for 324WT). However, all 493
significant enriched 328WT peaks and 142 of 144 significant enriched 324WT peaks
have positive enrichment in both matched pairs.

There are only two biological pairs per construct and the paired DESeq2 model
has one residual degree of freedom. Adjusted p-values describe the within-construct IP-versus-input tests;
construct-only categories are descriptive. Significance in one construct but
not the other does not demonstrate a construct difference; that requires a
direct construct-by-assay interaction test.
